# Raid v2.2.0

本次更新保留现有阅读工作区和主要交互，重点改善文档 AI、存储完整性、内存管理及桌面面板体验。

## 更新内容

- 支持通过受限附件工具读取完整文档和组合文件，生成的文本文件可导入文件区。
- 改善 Codex 会话恢复、历史选区图片恢复及流式输出，只显示最终回答内容。
- 历史图片追问使用已配置的视觉模型；API 断流、上游错误及输出长度限制会明确反馈。
- 统一 IndexedDB 连接和事务管理，修复并发保存覆盖索引、轻量记录覆盖聊天历史的问题。
- 优化 PDF 页面与画布释放、选区图片存储、长对话渲染及闲置资源清理。
- 改善桌面面板拖动、停靠、尺寸保持和持久化；更新应用图标及相关说明。

## 验证

40 项自动测试、TypeScript 类型检查、ESLint、生产构建、浏览器回归和桌面面板回归通过。120 页测试 PDF 六轮滚动的阅读进程组工作集峰值为 453 MB；包含 Codex 子进程时私有内存峰值为 243 MB。该结果仅代表测试场景，具体文档与机器的占用可能不同。

## 安装

下载 `Raid-Setup-2.2.0.exe` 安装。继续使用原有 v2 数据格式；可通过 `SHA256SUMS.txt` 核对安装包。项目源码可从本 Release 的源码归档或 `v2.2.0` 标签获取。
