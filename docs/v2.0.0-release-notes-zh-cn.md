# Raid v2.0.0

Raid v2.0.0 将应用进一步收敛为轻量、可扩展的 AI 阅读器。本次版本重点重做了文件组织、对话上下文、大型 PDF 性能和交互稳定性。

## 主要更新

- 新增轻量“组合”：文件可保持未分组，也可拖入组合；组合支持直接排序、双击重命名和无提示分解。
- 对话按所属文件折叠展示，并提供“对选区 / 对全文 / 对组合”三种明确范围；分解组合不会删除原有对组合对话。
- 文件选择器、系统拖放和剪贴板粘贴均支持一次导入多个文件；修复未分组文件被后续导入替换的问题。
- 标签栏与标签操作模式相互独立；标签可拖动、改名和跨文件跳转，AI 来源以正文后的临时角标显示。
- 大型 PDF 改用可见页按需渲染与附近页预加载，远处页面及时释放资源；OCR 延迟启动并在空闲后退出。
- 新增 Windows 文件右键“使用 Raid 打开”，可在通用设置中开关，卸载时自动清理。
- 优化侧边栏、浮动栏与导航栏的拖动反馈，修复折叠时按下跳动、排序松手跳动、组合重命名延迟等问题。
- 去除旧笔记模块，进一步聚焦阅读、检索、标签、批注和 AI 对话。

## AI 与选区

- 对选区会使用当前全部选区，不再限制选区数量。
- 当视觉模型可用时，可同时发送 OCR 文字和视觉选区原图，以便模型核对不精确的字符识别结果。
- 对全文在容量允许时使用精确全文；超大文档使用问题相关片段与跨全文代表性片段。
- 对组合会跨组合内全部文件检索，并尽量保留来自不同文件的证据。

## 安装

下载下方 `Raid-Setup-2.0.0.exe` 并运行即可。安装程序支持选择安装目录，并可创建桌面与开始菜单快捷方式。

> 建议升级前保留程序旁的 `RaidData` 目录备份。Raid 会继续使用其中的本地项目数据。
