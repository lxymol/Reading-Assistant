# Raid 存储与 AI 链路重构验证

本次在已有未提交改动的基础上修改，保留现有 UI、交互入口、数据库名称和桌面 v2 数据格式。下列内容仅描述本次增量，不将工作区原有改动计入本次成果。

## 改动

- `src/services/indexedDatabase.ts` 集中管理 IndexedDB 连接、升级关闭、事务提交和回滚，供项目及选区图片存储复用。
- 浏览器项目保存的读取、合并和写入放在同一个读写事务中，避免并发轻量保存覆盖刚写入的索引。
- 浏览器和桌面轻量聊天记录携带 `historyLoaded: false`；保存时保留磁盘中的历史，完整记录仍可显式清空历史。
- 浏览器项目列表逐条读取并只保留摘要，避免一次读取全部项目正文和聊天；删除项目也清理未纳入项目记录的源文件。
- 桌面 JSON、清单和源文件共用临时文件替换流程，失败后清理临时文件；写入二进制视图时复用其缓冲区且尊重视图边界。
- `server/chat-completions.mjs` 从路由模块拆出 API 流处理，显式报告上游错误、畸形数据、断流和长度限制。
- 前后端流读取器在完成或异常时取消剩余读取并释放锁，对单条流事件设置内存预算。
- 历史图片追问使用配置的视觉模型；恢复图片时保留 MIME 类型。请求取消监听覆盖附件准备阶段，并在结束后移除。

## 验证结果

- `node scripts/run-tests.mjs`：40 项通过，包含新增的轻量历史保护、二进制视图边界、流清理/失败检测和历史图片模型路由回归。
- `node node_modules/typescript/bin/tsc -b`：通过。
- `node node_modules/eslint/bin/eslint.js .`：通过。
- `node node_modules/vite/bin/vite.js build`：通过。
- `node tests/browser.test.mjs`：通过，含并发索引保存、历史保留、事务回滚、孤立源文件删除、PDF 资源释放及现有工作区交互。
- `node tests/desktop-panels.test.mjs`：通过，含拖动、尺寸保持、停靠区、持久化、重复停靠和关闭清理。
- `node tests/desktop-memory.test.mjs`：通过。120 页测试 PDF 六轮滚动，阅读进程组工作集峰值 453 MB；稳定阶段私有内存增长 -2 MB；包括 Codex 子进程的私有内存峰值 243 MB。

浏览器/桌面测试在沙箱内发生调试连接超时和 Electron 子进程启动失败，经允许在沙箱外以隔离临时配置重新运行后通过。本机 npm 启动器路径异常，因此使用 Node 直接调用项目脚本和本地工具，未修改系统环境。

内存结果仅覆盖现有测试 PDF 和测试流程；Codex 运行时各进程工作集之和为 574 MB，其中共享页会重复计数。这次没有做重构前后的性能对照，也没有对真实模型回答质量做基准评估；AI 改动改善请求路由及错误处理，不构成模型能力提升的量化结论。桌面多文件项目保存仍采用原有逐文件替换方式，不是跨文件数据库事务。
