# v2.2.0 发布后的重构

发布基线：`c575d69` / `v2.2.0`。这轮改动放在 `codex/post-v2.2.0-refactor`，不替换已发布的安装包或标签。

## 模块与行为

- `projectSession.ts`：将项目降载、重新加载及浏览器全文上下文组装从 App 拆出，保留原有 UI 和文档上下文行为。
- `projectWriter.ts`：桌面端按项目串行保存，读取等待已提交的保存请求；仅在写入成功后记录索引。相同不可变段落数组和索引状态的后续保存不再通过 IPC 重传正文。使用弱引用避免缓存阻止大型索引回收；失败和删除不会留下错误的“已保存”标记。
- `autosaveScheduler.ts` / `useProjectAutosave.ts`：保留 700 ms 防抖，持续编辑时每 3 秒尝试保存。项目切换、页面隐藏和卸载时尝试提交待保存内容。显式保存和删除会取消旧的待保存快照，避免陈旧快照回写。保存错误通过现有错误提示显示。
- `streamBatcher.ts`：每 40 ms 合并 AI 增量文本，减少 React 更新频率。完成时立即刷新；失败时保留已收到的部分答案并清理定时器。模型输入和最终文本不截断。

## 验证

- 46 项自动测试通过。
- TypeScript、ESLint、生产构建通过。
- 浏览器存储与 UI 回归、桌面面板回归通过。
- 120 页 PDF 六轮滚动内存回归通过：阅读工作集峰值 473 MB，稳定阶段私有内存增长 -5 MB，包含 Codex 时私有内存峰值 256 MB。共享工作集总和为 583 MB，其中共享页面会重复计数。
- 新增测试验证：失败后重新传送完整索引、保存/删除顺序、持续输入不饿死自动保存、显式操作取消陈旧快照、1,000 个文本增量合并为一次刷新、流失败保留部分文本及项目重新加载保留未保存元数据。

这些内存测试属于回归阈值验证，不是严格的前后对照，不能据此宣称总内存降低。索引去重依赖现有不可变状态更新约定，修改段落时必须创建新数组；缓存淘汰会回退到完整索引保存。页面关闭时的异步保存仍是尽力提交，不能保证进程被强制终止时写入完成。尚未重新生成此开发分支的安装包。
